# أدلة الامتثال وتقييم نضج البيانات: المختبرات

اثنا عشر مختبرًا لمقرر أكاديمية سدايا **LDS-DMG-207**، مدة كل منها 40 دقيقة في جلسة من 75 دقيقة. المختبرات صفحات
إرشادية بالعربية: الهدف، والملفات، وسياسة الذكاء الاصطناعي، وخطوات بدقائقها، وأسئلة تحقق، وتمرين إضافي ✱، وملاحظات
للمدرب. يعمل المشارك في جدول بيانات ومحرر مستندات، ولا يكتب كودًا.

كل المختبرات في جهة واحدة: **جامعة السها**، جامعة حكومية افتراضية تستعد لتقرير الامتثال السنوي ضمن التقييم الوطني
للبيانات. كل الأسماء والوثائق والأرقام وهمية.

## ما يحتاجه المشارك

- جدول بيانات: LibreOffice Calc أو Microsoft Excel، مع الفرز والتصفية وإزالة التكرارات والدوال COUNTIFS وMEDIAN.
- محرر مستندات لقاعدة الاستخدام والخطة.
- لا حساب ولا تثبيت آخر، ولا يُنزَّل أي نموذج، ولا يحتاج أي مختبر مساعد ذكاء اصطناعي ليكتمل.
- سياسة الذكاء الاصطناعي: دون أي مساعد في المختبر 2.1 وفي الاختبار الإشرافي؛ مساعد مرشد في بقية المختبرات (أسئلة
  بكلمات المشارك، بلا محتوى من الملفات)؛ استخدام كامل في المختبرين 3.1 و3.2 وفي المشروع الختامي لما صُنف «عام» فقط.
- ملفات الحالة مصنفة «مقيد» داخل الحالة، إلا `public_docs.xlsx` المصنف «عام». لا يدخل أي أداة ذكاء اصطناعي توليدي
  إلا ما صُنف «عام»، تطبيقًا لمبادئ الذكاء الاصطناعي التوليدي للجهات الحكومية.

## تشغيل الحلول

```bash
uv run labs/solutions/check.py            # كل المختبرات
uv run labs/solutions/check.py 2.2 3.1    # بعضها
```

ملف واحد يعلن اعتمادياته ويحتاج [uv](https://docs.astral.sh/uv/). يعيد حساب كل مفتاح من الملفات (الرفع الثنائي،
والصكوك، وطبقات المعايير، وأحكام البنود الستين وامتثال المواصفات، ومستويات الاستبانة، والمقاييس الأربعة، وأخطاء
المساعد وأنواعها، وترتيب الملاحظات، وما يُغلق في الدورة)، ويطبع الأرقام التي تقتبسها شرائح ما بعد المختبر و`PASS`
لكل مختبر، ولا يكتب شيئًا على القرص. لا يستدعي أي نموذج: ربط المساعد في المختبر 3.1 مكتوب سلفًا في
`mapping_pilot.xlsx` بديلًا مبرمجًا عن مساعد حقيقي، ليقيس المشاركون أخطاء معروفة.

## الملفات

| الملف | ما هو | المزروع فيه |
|---|---|---|
| `case_brief.txt`، `method_brief.txt` | موجز الحالة، والمنهجية كما يستعملها المقرر | |
| `sample_result.xlsx` | نتيجة الدورة الماضية للمواصفات العشرين | مواصفتان 100 بلا دليل، ومواصفة بقيمة 50 |
| `instruments.xlsx` | ستة عشر صكًا مرشحًا | سياسة مستبدلة، ومسودة، ومرجع دولي، ومجال يُقيَّم عبر جهة أخرى |
| `spec_extract.txt`، `criteria_template.xlsx` | عشرون مواصفة بصياغة مختصرة، والقالب، وجدول الاعتماد، ومسودة زميل | ست مسودات معيبة |
| `evidence_register.xlsx`، `sufficiency_rules.txt` | ستون بند دليل وقواعد الكفاية | إصدارات مستبدلة، ومعتمِد خطأ، وأدلة أُعدت للتدقيق، ولقطات بلا تاريخ، ونطاق جزئي |
| `questionnaire.xlsx` | اثنا عشر سؤال نضج وأدلتها | ثمانية ادعاءات أعلى من أدلتها، وادعاء أقل، وقفز فوق مستوى |
| `catalogue_extract.csv`، `quality_runs.csv`، `sharing_requests.csv`، `opendata_register.csv` | مستخرجات الأنظمة | صفوف مكررة، وأصول ملغاة وتجريبية، وقواعد معطلة، وتشغيلات بعد الفترة، وطلبات مسحوبة |
| `public_docs.xlsx`، `mapping_pilot.xlsx` | أربعون وثيقة «عام»، وربط المساعد، ومفتاح المقيِّم، وفهرس المواصفات | تسعة أخطاء بخمسة أنواع، ورقم مواصفة غير موجود، ومحضر «مقيد» في الدفعة |
| `error_summary_batch2.xlsx`، `usage_rule_template.txt` | الدفعة الثانية، وقالب القاعدة | نسبة خطأ عالية في التقارير |
| `observations.xlsx`، `ranking_rule.txt` | اثنتا عشرة مشاهدة | مشاهدتان لهما سبب واحد مرتين، وممارسات سليمة، وطلب حذف |
| `dg_findings.xlsx`، `plan_rules.txt` | ست ملاحظات في حوكمة البيانات | فجوات تشغيل عن فترة مضت لا تُغلق بوثيقة جديدة |
| `capstone_pack_template.txt` | قالب حزمة التدقيق التجريبي ومهمة المتابعة | |

صياغة المواصفات العشرين ومنهجية الامتثال إعادة صياغة مختصرة للتدريب من ضوابط ومواصفات إدارة البيانات الوطنية، وفيها عنوان
النص الرسمي. قواعد الكفاية، ومقياس النضج من 0 إلى 5، وتعريفات المقاييس، وقاعدة الترتيب، وقواعد الخطة أدوات خاصة بهذه
الحالة كُتبت لهذا المقرر، وليست أسئلة المؤشر الوطني للبيانات ولا مستوياته.

## إعادة توليد الملفات

```bash
uv run labs/_tools/prepare_files.py
uv run labs/_tools/write_solutions.py
```

الأول يولد كل ملفات `files/` ومفاتيح `solutions/reference/` ببذرة ثابتة، فيعطي البايتات نفسها في كل تشغيل. والثاني يكتب
الحلول المرجعية من المفاتيح.

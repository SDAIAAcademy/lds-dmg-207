# أدلة الامتثال وتقييم نضج البيانات

Compliance Evidence and Data Maturity Assessment

مسار التنفيذيين والقادة · أكاديمية سدايا · LDS-DMG-207 · المستوى 200

REPLACE: سطر واحد تحت العنوان: ما يستطيع المشارك فعله بعد المقرر

يؤدي المشاركون دور أخصائي الامتثال في جهة عامة افتراضية تستعد للتقييم الوطني السنوي للبيانات. فيحكمون على مستودع من الأدلة الواقعية (سياسات ومحاضر ولقطات شاشة وسجلات)، ويقدّرون درجات النضج، ويحسبون المقاييس التشغيلية، ويقيسون عدد المرات التي يربط فيها مساعد ذكاء اصطناعي وثيقةً بمواصفة غير صحيحة. والنتيجة حزمة أدلة جاهزة للتدقيق، وسجل ملاحظات مرتب بحسب المخاطر، وخطة تصحيحية، تُختبر جميعها في تدقيق تجريبي. أما خرائط الطريق الموجهة إلى الجهات الراعية فموضوع المقرر LDS-ADV-202.

**الصيغة:** دورة مكثفة: 3 أيام تدريبية ويوم للمشروع الختامي، مع عمل تحضيري موجه ومهمة متابعة متعقَّبة

**صفحة المقرر:** https://sdaiaacademy.github.io/lds-dmg-207/

## نواتج التعلم

| | نواتج التعلم | المستوى | الدليل |
|---|---|---|---|
| LO1 | يصف كيف يقيس التقييم الوطني للبيانات الامتثال والنضج والتميز التشغيلي، والأدلة التي يحتاج إليها كل جزء منه، استنادًا إلى المنهجية المنشورة ونتيجة نموذجية | Awareness | خريطة من صفحة واحدة تربط كل جزء بأنواع أدلته، يُتحقق منها مقابل المنهجية |
| LO2 | يعدّ معايير قبول تحدد ما يجب أن يكون موجودًا، ومن اعتمده، وما يثبت أنه مطبق فعلًا، استنادًا إلى عشرين مواصفة من ثلاثة مجالات | Applied | ورقة معايير تُراجَع مقابل إجابة نموذجية |
| LO3 | يصنف الأدلة إلى كافية أو جزئية أو غير كافية، ويسجل السبب والفجوة، على ستين بندًا اصطناعيًا، بعضها قديم أو غير موقَّع أو خارج النطاق | Applied | سجل كفاية يتفق بنسبة 85% على الأقل مع مفتاح المقيِّم |
| LO4 | يحسب درجات النضج والمقاييس التشغيلية، ويتتبع كل مستوى يُدّعى حتى دليله، استنادًا إلى مستخرجات من كتالوج البيانات وجودة البيانات ومشاركة البيانات والبيانات المفتوحة | Applied | استبانة مقدَّرة درجاتها، وإحالاتها إلى الأدلة كاملة |
| LO5 | يقيّم ربطًا للوثائق بالمواصفات أجراه مساعد ذكاء اصطناعي، ويقرر المواضع التي يجوز فيها لعملية الامتثال استخدامه، استنادًا إلى ربط المساعد ومفتاح المقيِّم | Performance | تحليل للأخطاء وقاعدة استخدام مكتوبة |
| LO6 | يسلّم حزمة أدلة مع سجل ملاحظات مرتب بحسب المخاطر وخطة تصحيحية محددة المسؤولين والمواعيد، استنادًا إلى أدلة الجهة موضوع الحالة وفي تدقيق تجريبي | Performance | الحزمة والسجل والخطة، يُناقَش ثلاثتها في التدقيق |
